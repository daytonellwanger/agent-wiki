# Agent Wiki

A project for maintaining a wiki about AI agents.

This project is primarily an exercise in learning how to build AI agents — but the best way to learn is to build something useful. So I hope that the wiki is genuinely useful as a source of information.

Contributions welcome: submit a PR and let's learn together.

## Structure

This project spans 4 repos (this one plus three others). This repo serves as the entry point, describing the overall design and how the other repos relate to each other.

### agent-wiki-wiki

This repo is located [here](https://github.com/daytonellwanger/agent-wiki-wiki).

These are the actual wiki contents, which are just a collection of markdown files. These can be written by AI or humans, but I personally review all changes. You may submit your own changes (either written by you or AI) via PR.

### agent-wiki-maintainer

This repo is located [here](https://github.com/daytonellwanger/agent-wiki-maintainer).

This is the agent that helps write and maintain the wiki.

### agent-wiki-website

This repo is located [here](https://github.com/daytonellwanger/agent-wiki-website).

This is for serving the wiki contents as a website, currently hosted at [agentwiki.daytonellwanger.com](https://agentwiki.daytonellwanger.com).
